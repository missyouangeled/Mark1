### 启动机制修复（点点要求根本修复）

**问题1：切换模型时"正在加载系统"提示消失**
- 根因：旧版 sH 函数（Control UI bundle JS 的 chat.inject 3条消息）在 OpenClaw 2026.7.1-2 版本被移除
- 当前版本模型切换走后端 enqueueSystemEvent，注入不可见系统事件
- session:patch hook 不支持 push 可见消息，无法通过 hook 恢复
- **修复方案**：在 AGENTS.md 顶部加硬规则，要求模型每次启动/切换后先输出"正在加载系统..."
- 加注释说明为什么存在这条规则，标注"永远不能取消"
- 这是软约束（非代码层面强制），但配合 AGENTS.md 自动注入，所有模型都能看到

**问题2：AGENTS.md 启动流程被跳过（包括 COGNITION.md）**
- 根因：AGENTS.md 的启动流程依赖模型主动 read 文件，不同模型遵循度不同
- **修复方案**：把 COGNITION.md 核心内容精简后内联到 AGENTS.md 末尾
- AGENTS.md 已被 OpenClaw 自动注入 system prompt，所有场景（新会话/切换模型/compaction 后）都能看到
- COGNITION.md 原文件保留作为档案，不再需要模型主动 read
- AGENTS.md 从 2399 chars 增长到 8728 chars（bootstrapMaxChars 20000 限制内）

**postCompactionSections 更新**
- 新增"硬规则：启动提示（永远不能取消）"段落
- 新增"认知沉淀（原 COGNITION.md，由 OpenClaw 自动注入）"段落
