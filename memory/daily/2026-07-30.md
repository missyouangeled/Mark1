- conftest 收集阶段先加载 → import 失败 → 整个 tests/ 目录全判 ERROR

- 修复后：1346 用例可收集，1313 通过，通过率 99.6%

### 修复 2：test_armor_compress.py 的 fd 泄漏崩溃（3 ERROR）
- 现象：整文件连跑到某用例后 pytest 整体 INTERNALERROR: `OSError: [Errno 9] Bad file descriptor`
- 用 strace + monkeypatch os.close 追踪，定位到 `armor.py::_try_acquire_compact_lock`
- **根因（产品代码真实健壮性缺陷）**：pytest fd 捕获模式下 stdout(fd 1) 空闲，`os.open(compact.lock)` 拿到 fd 1，用完 `os.close(fd)` 把 pytest 的 stdout 关掉 → 后续 flush 崩
- 修复：锁 fd 若落在 0/1/2，用 `fcntl.F_DUPFD` 重定位到 >=3，并把低位 slot 用 `os.dup2(/dev/null)` 补回，保证标准流不被误关。生产环境无害，测试环境不再崩

### 修复 3：2 个断言失败（测试迁移遗留）
- `test_config::test_workspace_exists_or_default`：conftest autouse fixture 改了 HOME，`Path.home()` 拿到假路径。改为断言 WORKSPACE 结构（`.parts[-2:] == (.openclaw, workspace)`）
- `test_smart_crusher::test_instance_is_smartcrusher`：conftest reload 模块导致类身份错位，`isinstance(旧类)` 失败。改用 `type(c).__name__ == "SmartCrusher"`
