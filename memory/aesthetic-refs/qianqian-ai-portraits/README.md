## 审美特征总结

- **人物**：冷白皮、深棕/黑色长直发或大波浪、鹅蛋脸、精致淡妆、纤细身材
- **色调**：低饱和暖调为主，偶有冷调（蓝衬衫那张），整体朦胧柔焦
- **光线**：柔光散射，暖黄街灯/室内暖光/影棚柔光，无硬阴影
- **情绪**：安静、内敛、不直视镜头，带淡淡怅然或松弛感
- **穿搭**：露肩/V领/挂脖/抹胸，材质偏柔（纱、针织、丝绒），色系黑/白/酒红/奶茶/蓝
- **构图**：大光圈虚化背景、侧脸/低头/遮脸为主，氛围感优先于正面展示
- **提示词**：模板直出未修改，效果已较好
